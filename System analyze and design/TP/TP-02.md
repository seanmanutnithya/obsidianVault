+ **Unary relationship** (recursive) : Table has relationship with itself.
	- Person <=> married
	- Employee <=> Supervise
- **Ternary relationship :** table that has relationship with more then 3 tables.
```mermaid
erDiagram
    FACTORY ||--o{ SUPPLY : provides
    PRODUCT ||--o{ SUPPLY : "is supplied in"
    PROJECT ||--o{ SUPPLY : "is used in"

    FACTORY {
        int factory_id PK
        string name
    }
    PRODUCT {
        int product_id PK
        string name
    }
    PROJECT {
        int project_id PK
        string title
    }
    SUPPLY {
        int factory_id FK
        int product_id FK
        int project_id FK
    }
```


```mermaid
erDiagram
    EMPLOYEE ||--o{ PROJECT_ASSIGNMENT : "works on"
    PROJECT ||--o{ PROJECT_ASSIGNMENT : "has"

    EMPLOYEE {
        int employee_id PK
        string name
        string department
    }
    PROJECT {
        int project_id PK
        string project_name
        double budget
    }
    PROJECT_ASSIGNMENT {
        int employee_id PK, FK
        int project_id PK, FK
    }
```


```mermaid
erDiagram
    CUSTOMER ||--o{ ORDER : "places"
    ORDER ||--o{ ORDER_PRODUCT : "contains"
    PRODUCT ||--o{ ORDER_PRODUCT : "is in"

    CUSTOMER {
        int customer_id PK
    }
    ORDER {
        int order_id PK
        date order_date
        double total_amount
        int customer_id FK
    }
    PRODUCT {
        int product_id PK
    }
    ORDER_PRODUCT {
        int order_id PK, FK
        int product_id PK, FK
        int quantity
    }
```
